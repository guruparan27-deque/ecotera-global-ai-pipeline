Quality & Geography Notes

Geographic scope: The live page is limited to Singapore, Malaysia, Indonesia, Brunei Darussalam, Thailand, Viet Nam, Cambodia, Lao People's Democratic Republic, Myanmar, and the Philippines.

SDG 6: The current Southeast Asia subset contains verified records for all 10 target countries. Only records with usable values are included in the live dataset.

Water Quality Portal: The downloaded WQP sample contains coordinates in the United States, so these records are not shown on the Southeast Asia page.

GEMStat: The current GEMStat station metadata does not contain verified stations in the 10 target countries, so GEMStat records are not shown on the live Southeast Asia page.

No country is assigned by guesswork. Records are included only when the source provides sufficient evidence for Southeast Asian inclusion.

Map: No point map is shown because the current Southeast Asia live subset does not contain a verified coordinate point dataset.
